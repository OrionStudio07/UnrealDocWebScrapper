# Security Policy

## Supported Versions

Only the latest release of UnrealDocWebScrapper is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of UnrealDocWebScrapper and our integration layers seriously. If you find a vulnerability, please report it immediately.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please send a detailed security report outlining:
1. The nature of the vulnerability.
2. Steps to reproduce or proof-of-concept code.
3. Potential impact on local crawl systems or integration targets like `orion collab`.

Please report vulnerabilities directly via email or the support channel specified in [SUPPORT.md](SUPPORT.md). We will acknowledge your report within 48 hours and work with you to patch the issue before public disclosure.
