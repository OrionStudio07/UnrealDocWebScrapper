# Support for UnrealDocWebScrapper

Welcome! If you are encountering issues running the scraper or integrating the generated Obsidian Vault with your AI agent frameworks (e.g. `orion collab`), here are the channels to get help:

## Documentation

Before raising support requests, check the comprehensive documentation:
- [Getting Started Guide](docs/getting_started.md)
- [Configuration Reference](docs/configuration.md)
- [System Architecture & Agent Integration](docs/architecture.md)
- [Developer Setup](docs/development.md)

## Bug Reports and Questions

- **Bug Reports:** If you discover a bug in the Crawler engine, the Sitemap Parser, or the Wiki Link Converter, please open an issue using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
- **Feature Suggestions:** For enhancement ideas, use our [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).
- **Questions / Orion Collab Integrations:** For questions on how to structure the knowledge bases or build custom agents parsing the wiki-links, please open a discussion on the GitHub repository or reach out in the collaborative workspace chat.
